🛒 Loja de Camisas de Times (E-commerce)
Projeto de uma aplicação web para e-commerce focada na venda de camisas de times esportivos. O objetivo deste projeto é demonstrar habilidades práticas no desenvolvimento de interfaces web modernas, componentização e uso de tipagem estática para garantir a integridade dos dados na interface do usuário.

✨ Funcionalidades
Listagem de Produtos: Catálogo de camisas com cards interativos mostrando imagem, nome do time e preço.
Filtragem e Categorização: Organização dos produtos por ligas, esportes ou times para facilitar a navegação do usuário.
Carrinho de Compras: Lógica de adição, remoção e cálculo de valor total dos itens selecionados.
Detalhes do Produto: Página ou modal de visualização expandida com detalhes da camisa (tamanhos disponíveis, tecido, etc.).
Interface Responsiva: Layout adaptável para diferentes tamanhos de tela (Desktop, Tablet e Mobile).
🚀 Tecnologias Utilizadas
Este projeto foi desenvolvido com as seguintes tecnologias:

TypeScript: Tipagem estática para garantir maior segurança e previsibilidade do código.
HTML5: Estrutura semântica da aplicação.
CSS3: Estilização e responsividade (ou Tailwind CSS, caso o Lovable tenha utilizado).
React (Se aplicável): Biblioteca para construção de interfaces e componentes reutilizáveis.
Vite (Se aplicável): Ferramenta de build e desenvolvimento local rápido.

💻 Como Rodar o Projeto Localmente
Para clonar e executar este projeto na sua máquina, siga os passos abaixo:
# 1. Clone o repositório
git clone https://github.com/PedroViniciusO/NOME_DO_REPOSITORIO.git

# 2. Acesse a pasta do projeto
cd kickoff-checkout

# 3. Instale as dependências
npm install
ou
yarn install

# 4. Inicie o servidor de desenvolvimento
npm run dev
ou
yarn dev

Após executar o comando acima, o terminal mostrará o link (geralmente http://localhost:5173) onde a aplicação estará rodando. Basta clicar ou colar no navegador.

Este projeto foi desenvolvido com foco em:
